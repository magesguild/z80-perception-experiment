# SCC-derived text documents

These plain-text files were extracted or copied from the SCC corpus for easy
consumption by participants and the operator. They are not substitutes for
observing the SC100.

| Local document | SCC source | Purpose |
|---|---|---|
| `cpm22-user-manual.txt` | `MPMII-Z80_RCBUS-Z2-BINDIST/doc/cpm22-user-manual.pdf` | CP/M 2.2 OS, BDOS, files, console |
| `aztec-c-ii-z80-user-manual-1.05.txt` | `MPMII-Z80_RCBUS-Z2-BINDIST/doc/Aztec_C_II_Z80_User_Manual_1.05_Sep83.pdf` | Aztec C Z80 manual |
| `aztecman.txt` | `MPMII-Z80_RCBUS-Z2-BINDIST/doc/AZTECMAN.TXT` | Aztec C plain-text manual |
| `htcz80.txt` | `MPMII-Z80_RCBUS-Z2-BINDIST/doc/HTCZ80.TXT` | Compiler/toolchain notes |
| `scm-rcbus-readme.txt` | `MPMII-Z80_RCBUS-Z2-BINDIST/readme.md` | RCBus/SIO/CTC and console hardware context |
| `xm29-serial-example.asm.txt` | `scc/src/xm29.asm` | Comparative Z80 serial/BDOS example |
| `scc-serial-interface-guide.txt` | This repository | Reading order and serial-layer boundary |

`Utility Software Manual.pdf` was not included as text because its SCC PDF has
no usable text layer in this environment. It is not required for HMAN.

Checksums for the extracted/copy files are in `SCC_TEXT_MANIFEST.sha256`.
