# Candidate Work Area

**Template.** This directory is where each candidate builds its deliverable.
At the stop line it should contain:

```
work/
  README.md          build steps, command summary, implemented/not-implemented
  src/               editor source (C and any assembly seams)
  build/             submit scripts (.SUB) and any build notes
  ED.COM             the built deliverable, if produced (optional but encouraged)
```

The base repository ships only this README and an empty `src/` and `build/`
structure (add them when needed). Candidates add their own prior code here as
part of their working environment. Everything under `work/` belongs to the
candidate and is committed at the stop line.
