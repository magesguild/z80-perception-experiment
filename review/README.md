# Review Area

**Contents:**

- `JUDGE_REPORT.md` — template for the judge's per-arm rubric scores (this dir).
- `ANALYSIS_REPORT.md` — template for the per-arm analysis across the four
  measurements.

The analysis is led by the **human operator (Gaius)** and **Melpomene**, the
most expert of the participants, per `docs/ANALYSIS_PLAN.md`. The judge scores
each arm with `RUBRIC.md`; the analysis team then interprets results across the
four measurements (context-use efficiency, durable-memory/re-entry efficacy,
token and monetary spend, correctness and quality).

Blinding is not fully achievable in the pilot (single judge, candidates
recognizable); that limitation is recorded in `RUBRIC.md` and in each judge
report. Melpomene's dual role as analyst and Arm B is recorded in the protocol
and in every Arm B analysis report. A second qualified judge and a blinded pass
are planned refinements.
