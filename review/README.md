# Review Area

**Template.** The judge (Gaius) scores each arm's deliverable after its stop
line using `RUBRIC.md`, and fills `review/JUDGE_REPORT.md` for each arm.

Contents:

- `JUDGE_REPORT.md` — template for the judge's per-arm report (this file).

Blinding is not fully achievable in the pilot (single judge, candidates
recognizable); that limitation is recorded in `RUBRIC.md` and in each judge
report. A second qualified judge and a blinded pass are planned refinements.
